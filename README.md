# U2-ejercicio20
### Ejercicio: El Sistema de Gestión de Flotas de Vuelos y Torres de Control

**Objetivo:** Modelar la comunicación entre objetos en Java mediante el envío de mensajes entre aviones y una torre de control, permitiendo solicitar autorizaciones de aterrizaje, verificar la disponibilidad de la pista y actualizar los estados de vuelo según las respuestas recibidas.

Desarrollo de un sistema de coordinación aérea utilizando las clases `Avion`, `TorreControl` y `Main`, aplicando encapsulamiento, referencias entre objetos, validaciones y comunicación entre objetos.
